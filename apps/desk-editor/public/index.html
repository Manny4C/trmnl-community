A useful agent
doesn’t need to be loud.
Desk Editor is a rules-based agent running off the device. It collects public data, applies a small editorial policy, and returns a compact edition for TRMNL to render. It uses no language model and cannot read your calendar, tasks, inbox or company accounts.
Stories come from up to 24 recent Hacker News front-page posts. Release data comes from the selected project’s latest stable GitHub release. Optional weather comes from the US National Weather Service. Each sourced card keeps a link and real timestamps. These are bounded snapshots, not comprehensive monitoring.
Built for the TRMNL community by Manuel. Free to use, with no new paid service required. Feedback, corrections and support belong in the public source repository. The recipe’s design and our code are reusable; source content keeps its original rights.
