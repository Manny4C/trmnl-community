Sounds Like My Company — private plugin setup

1. Create a Private Plugin at https://trmnl.com/plugin_settings/new?keyname=private_plugin
2. Choose Polling, GET. Paste form-fields.yml into Form Fields. Save.
3. Use a public product description (10–300 characters), optional customers and keywords. Your company name is a label, not a website lookup. Fields are placed in a request URL; never enter confidential information.
4. Set polling URL to the single line below:
https://sounds-like-my-company.vercel.app/api/matches?name={{ company_name | url_encode }}&profile={{ profile | url_encode }}&audience={{ audience | url_encode }}&keywords={{ keywords | url_encode }}&exclude={{ exclude | url_encode }}&days={{ days }}&source={{ source }}&order={{ sort_order }}&count={{ result_count }}&format=trmnl
5. Refresh hourly or slower. There is no serverless transform or personal API key.
6. Paste shared.liquid into Shared. Paste the four matching .liquid files into Full, Half vertical, Half horizontal and Quadrant. Save every tab.
7. The launch-radar design uses red/yellow accents on color-capable palettes and high-contrast black/white fallbacks on 1-bit devices. Color is never the only signal: numbered cards, source badges and text remain readable in B&W. Full screen uses two columns for six/eight results and a roomy single column for three. Preview your device type. Full shows up to your 3/6/8 setting, half shows two and quadrant one. Force a refresh and add to your playlist if needed.

Matching uses title words, explicit related-word groups and customer wording, not an LLM or verified competitor research. Must-have keywords are alternatives: any one must appear as a word. Exclusions remove any matching word. No-match results stay empty.
Coverage is bounded to Launch HN and Show HN. Up to two specific words from the public profile/keywords are sent to HN Search; at most 100 unique announcements are checked through official HN API per refresh. Show HN may be a project rather than a company. Dates are post dates. Older cached and partial-source editions are labeled. Cold outages return 503 instead of a fabricated edition.

Personalized clickable links (October 16 update)
Every successful TRMNL poll saves the public settings once and returns a stable 12-character links code. Full screen adds a black/white QR with a quiet zone; all four layouts show the code. Scan the full-screen QR or go to https://sounds-like-my-company.vercel.app and enter the code in “Open your TRMNL links.” The page applies the same settings and provides live clickable announcement links. It may show newer matches than an older device screen; check its source timestamp. Bookmark the page for next time.

There is no account or device credential. The code is a shareable link, not proof of TRMNL ownership. Anyone with it can read the public profile and matches. Never enter confidential company information. Different settings produce a different stable code; old pages remain available. Profile records are immutable, stored in private Vercel Blob on Manuel’s personal Hobby team (free quotas; no overage billing). No per-viewer AI calls. If storage is unavailable/quota-limited, matching still works but the device omits the new code/QR rather than displaying a nonexistent page. Existing saved pages retain their code and can be retried later. No local-memory-only codes or device API keys.

An existing installed Recipe must receive the updated Shared and four layout tabs to show code/QR. Updating the website alone does not save those tabs to TRMNL. Browser-dependent changes remain deferred under the owner's no-screen-control instruction; do not claim the new QR/code is on the physical device until saved and verified.
